GitHub Pages公開:
1. 新しいGitHubリポジトリを作る（例: shinomiya-works）
2. このフォルダ内のファイルを全部アップロードしてCommit
3. Settings → Pages
4. Source: Deploy from a branch
5. Branch: main / (root)
6. Save
7. 数分後に公開URLが発行されます
